1000-Introduction


INTRODUCTION TO SymZilla

SymZilla is a simple browser for SymbOS. It displays DOX documents containing text, links and SGX graphics. Local DOX files continue to work as before.

HTTP and HTTPS addresses are fetched through a configured GB-proxy. The proxy converts the remote page to DOX before SymZilla displays it, so SymZilla does not need to parse HTML or negotiate HTTPS itself.

1100-Feature overview


FEATURES

* Open local DOX documents.
* Open HTTP and HTTPS addresses through GB-proxy.
* Follow GET links in proxy-generated documents.
* Select SGX colour depth automatically from the active SymbOS screen mode.

SymZilla advertises whether the current screen can display 2, 4 or 16 colours. GB-proxy then generates matching SGX graphics. This is based on the live screen mode, not just the computer type, so CPC and PCW colour limits are respected and an MSX in a 4-colour mode still receives 4-colour images.

2000-Using SymZilla


USING LOCAL DOX FILES
Enter or select a local DOX pathname as usual. Local files do not require a network connection or GB-proxy.

USING GB-PROXY
Open Options and set the GB-proxy address to the host name or IP address and port of your proxy machine, for example gb-proxy:5001. The Network Daemon must be available in SymbOS and the proxy must be reachable from the machine.

Enter an address beginning with http:// or https:// in the location field. SymZilla contacts GB-proxy over HTTP; for an HTTPS address, GB-proxy performs the secure upstream connection.

Forms and POST requests are not supported yet. Links using the GET method are supported. Pages that cannot be converted by GB-proxy are displayed as DOX error documents when possible.
